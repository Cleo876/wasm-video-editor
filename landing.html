ADVANCED EXTENSION

Rubicon Graph Engine

Traditional video editors stack effects in layers, which quickly becomes a tangled, restrictive mess. The WASM Video Editor breaks those limits with the Rubicon Graph Engine—a true, professional node-based compositing workspace.

Like the industry-standard tools used in Hollywood feature films, nodes allow you to wire media, masks, and color corrections together visually. You aren't just applying an effect; you are building a custom pipeline. Because it's powered by WebAssembly, this complex math happens instantly in your browser.

Try it yourself right now: Switch the media buttons to load a looping video, then drag the sliders on the Color Corrector node to see zero-latency, real-time rendering.

What is a Ghost App?

A Ghost App is a real website given a permanent home on your computer. The installer creates a dedicated, sandboxed browser profile so the WASM Video Editor never touches your personal browsing data, never conflicts with extensions, and works completely offline after the first launch. It feels like a purpose‑built application — because it is. No Electron wrapper, just your existing browser running clean.
